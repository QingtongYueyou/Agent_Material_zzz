# ui 目录说明

## 目录职责
`ui/` 负责 Streamlit 前端展示层，包括对话区、执行轨迹、样式和可视化渲染。

## 文件与功能
- `chat.py`
  - 左侧对话区渲染与输入框
- `components.py`
  - 顶部栏、右侧工作流轨迹、调试面板、数据追溯
- `visualization.py`
  - 中栏 3DGS 与图表渲染
  - splat 模型自动匹配与回退
- `styles.py`
  - 全局 CSS 主题与组件样式
- `__init__.py`
  - 包初始化文件

## 界面结构
- 左侧：用户输入与助手回答
- 中间：结构可视化（3D + 图表）
- 右侧：工作流状态（步骤、耗时、错误）

## 渲染规则
- 右侧面板展示系统轨迹，不替代左侧主回答。
- 3D 模型匹配优先级：
  1. `mp-id_formula`
  2. `formula`
  3. `object.ply` 回退

## 维护建议
- 新增样式尽量集中在 `styles.py`，避免散落在组件内联字符串。
- 保持组件拆分粒度，避免单文件过大难维护。
