# config 目录说明

`config/` 统一管理路径常量和环境变量。

## settings.py

主要配置：

- 项目路径：`BASE_DIR`、`CIF_DIR`、`STATIC_DIR`
- 3DGS 路径：`SPLAT_DIR`、`SPLAT_SOURCE_DIR`、`SPLAT_DERIVED_DIR`
- 指标路径：`METRICS_DIR`、`RENDER_METRICS_FILE`、`INTERACTION_METRICS_FILE`
- Materials Project：`MP_API_KEY` 或 `MAPI_KEY`
- LLM：`POE_API_KEY`、`POE_API_BASE_URL`、`LLM_MODEL_ID`、`LLM_TIMEOUT_SEC`
- MCP：`MCP_ENABLED`、`MCP_SERVER_URL`、`MCP_API_KEY`、`MCP_TIMEOUT_SEC`
- Spark：`SPARK_ROOT`、`SPARK_AUTO_INGEST`、`SPARK_AUTO_VARIANT`

敏感信息只放在 `.env` 或系统环境变量中。
